## 2. 令牌使用规则

- 命名空间：`--color-*`（颜色）、`--metric-*`（尺寸/间距/圆角/字号）、`--type-*`（字体族）。
- **禁止在业务代码里写死色值**。涨跌色一律用 `--color-market-up`（红）/ `--color-market-down`（绿），A 股约定：涨红跌绿，勿用欧美配色。
- 浅/深色切换：同一变量名在两套主题下取值不同，切换主题只换变量表，不换组件样式。
- 关键映射（Light / Dark）：
  - 页面底 `--color-bg-base`：#F9FAFB / #0F0F1A
  - 卡片底 `--color-bg-surface`：#FFFFFF / #1E293B
  - 主色 `--color-brand-primary`：#2563EB / #3B82F6
  - 涨 `--color-market-up`：#DC2626 / #F87171；跌 `--color-market-down`：#059669 / #34D399
  - 微信绿 `--color-brand-wechat`：#07C160（登录按钮专用）

## 5. 状态矩阵（每个页面 / 列表必须覆盖）

| 状态 | 表现 | 关键规则 |
|---|---|---|
| 加载中（首屏） | 骨架屏，形状与真实内容一致 | 保持布局不跳动，≥ 300ms 才显示 |
| 加载中（增量） | 列表底部 spinner | 请求中按钮进入加载态并禁止重复提交 |
| 空态 | 圆形插画占位 + 标题 + 描述 + 主操作 | 例：股票池空 → 「创建股票池」按钮 |
| 加载失败 | 标题「加载失败」+ 描述 + 「重新加载」 | 保留顶栏与已有操作，不整页白屏 |
| 无网络 | 全屏占位（非 Toast） | 「检查网络」引导到系统设置 |
| 无权限 403 | 占位 + 「返回首页」 | 不展示任何数据轮廓 |
| 未登录 / Token 失效 | 「登录已失效」→ 跳登录页 | 登录成功后返回原页面 |
| Toast | 深色胶囊 1.6s 自动消失 | 仅用于轻反馈（已加入自选等） |
| Dialog | 遮罩 + 居中弹窗 | 用于删除等不可逆操作，二次确认 |
| ActionSheet | 底部弹出 | 破坏项（删除）用 `--color-market-up` 红色 |

## 6. 表单与交互规则

- 键盘弹起时：底部固定按钮**上移至键盘上方**，页面整体可滚动，聚焦字段不被遮挡。
- 校验失败：输入框描边 `--color-market-up`，错误文案 11pt 置于输入框正下方；**逐字段校验、首次失焦触发**（自定义名称 ≤12 字符；最大持仓数 1–20 整数；初始资金 ≥10,000）。
- 提交：点击后按钮进入加载态（三点动画），成功后 Toast + 返回；失败保留已填内容。
- 选择器字段（策略类型 / 股票池）用底部 ActionSheet 或 picker，不新开页面。
- 输入框状态五种：默认 / 聚焦（主色描边）/ 已填 / 错误 / 禁用（见设计系统第 4 页）。

## 7. 数值与文本格式规范

| 数据 | 格式 | 示例 |
|---|---|---|
| 价格 | 保留 2 位小数，千分位不加 | `1682.50` |
| 金额（万元及以上） | 千分位 | `1,000,000` |
| 涨跌幅 | 符号 + 2 位小数 + `%` | `+2.31%` / `-1.08%` |
| 涨跌额 | 符号 + 2 位小数 | `+23.80` |
| 大市值 | 亿为单位 | `21145亿` |
| 数字字体 | `--type-font-family-number`（Inter），等宽数字 | 表格/行情列必须用数字字体 |
| 中文字体 | `--type-font-family-base`（Noto Sans SC） | 标题 Bold、正文 Regular、辅助 Medium |

字号阶梯：24 / 15 / 14 / 13 / 12 / 11 / 10 / 9（`--metric-font-size-*`）。
