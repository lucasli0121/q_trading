设计令牌预览

数据与样式均直接来自 colors/theme.py，非手工誊抄。
浅色取值定义在 :root（系统默认主题为浅色），深色取值定义在 body.qs-dark（本页为同屏并列改写为 .dark-scope）， 两者同时存在于同一张共享样式表；切换主题只切换 body 上的 class，浏览器立即重算，不需要重新渲染页面。
下方色块一律用 var() 取色 —— 若某个令牌或颜色通道没生成出来，色块会是空的。

颜色通道：CSS 无法给 var() 追加透明度（var(--qs-text)88 是非法声明， 整条 color 会被浏览器丢弃）。需要半透明时用通道变量拼接 rgba(var(--qs-primary-rgb), 0.15)；Python 侧对应 ThemeManager.var_rgba()（CSS 场景）与 get_rgba()（canvas 场景）。 通道由令牌自动派生，因此对任意令牌都成立，不存在漏配。
