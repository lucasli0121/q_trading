# CLAUDE.md

策略回测

## Project Overview

策略回测模块，启动工作流进行回测，并通过API保存回测结果

### 回测流程
按照回测流程
- 读取股票池，按照股票池给的股票进行回测
- 指定基准
- 读取指定的策略
- 设置初始资金，滑点，手续费
- 指定时间范围，根据实际范围获取股票池中的股票数据
- 执行策略
- 输出结果
- 和基准对比，输出对比结果
- 结果入库


## 编码规范

- 所有函数必须有类型注解，代码符合pylance规范
- 所有函数都要求函数注释，文件头，函数头注释
- 函数参数，类成员定义都要求有类型说明
- 字符串一律使用双引号
- tests目录测试符合unittest规范
