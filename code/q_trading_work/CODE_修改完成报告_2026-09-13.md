## 五、额外修复的真实 BUG（不在原问题单内）

**`strategy/swing_trading_strategy.py` → `_get_code_prev_sr_point` 崩溃**

- 现象：`InDaySRFactor.calculate` 在**日线数据不足**（新股、停牌复牌、数据缺口）时返回浮点 `0.0` 而非 DataFrame，
  原样返回后 `_save_sr_points` 在 `sr_df.empty` 处抛
  `AttributeError: 'float' object has no attribute 'empty'`。
- 影响：该调用位于 `before_trading` 的**股票池循环内**，只要池里有**一只**股票数据不足，
  整个池子的盘前准备（枢轴点位计算）就会中断；`_get_sr_points` 也会向下游返 `float`。
- 修复：`_get_code_prev_sr_point` 统一收敛返回值，非 DataFrame 时记 warning 并返回空表（下游按「无点位」处理）。
  修复后 `tests/strategy/test_swing_trading_strategy.py` 由失败转为通过。
