# 回测报告：日内熔断（连续亏损卖出停买 / 连续卖飞停卖）

**回测区间**：2026-07-21 09:30:00 ~ 2026-10-13 15:00:00（分钟频）
**策略 × 股票池**：强趋势 / 波段 / 成交量 × 实际持仓 / 自选股 / 科技池 = 9 组 × 2 套口径 = 18 次，另与上一轮的 9 组对照
**提交口径**：门槛全开 + 成交间隔 30 分钟 + 滑点 0.02 元（与上一轮 `_bt_v5` 完全一致）

## 一、要解决的问题

上一轮（27 组）测出硬止损的失效机制是**空转**：止损把仓位清零后，「缩量回调」这个买入条件往往仍成立，成交间隔一到就买回同一只票、再被同一个止损打出来。成交量策略上「止损后 2 小时内再入场」占止损笔数的 60%~100%，其中 93% / 81% / 80% 又被同一条件二次止损。止损只把大亏切成小亏，总亏损没变，笔数涨到 2.4~2.5 倍。

本次按用户定稿的三条口径加**日内熔断**：

| 项 | 规则 | 作用域 | 解除 |
|---|---|---|---|
| 买入侧 | 连续 3 次亏损卖出后，当日不再对该股发买入信号 | 单只股票 | 次日自动 |
| 卖出侧 | 连续 3 次卖飞（卖出后当日价格涨过该次卖出价）后，当日不再对该股发卖出信号 | 单只股票 | 次日自动 |

「连续」的定义：中间夹一笔非亏损（或非卖飞）的卖出即清零。买入侧的计数**跨日累计**，不因换日而清。被熔断否决的信号**不写回任何计数**（那笔交易没发生）。

常量：`INTRADAY_BREAKER_ENABLED`（默认开）、`INTRADAY_BUY_BLOCK_LOSS_SELLS=3`、`INTRADAY_SELL_BLOCK_FLY_SELLS=3`，均在 `BaseStrategy`。回测对照开关 `--no-intraday-breaker`。

### 判定口径里两处需要明说的近似

**「亏损」用「卖出价 < 买入信号价」判定。** 策略按设计约定恒收空持仓（X1），拿不到 `cost_price`，也拿不到真实成交价；它自己记录的「本笔建仓的买入信号价」是链路里唯一可用的建仓基准。回测里成交价与信号价出自同一根 bar 的 `price`，两者只差滑点（0.02 元 ≈ 0.03%），因此该代理在正负 0.03% 附近会误判，量级可忽略。

**没有建仓基准的卖出既不计也不清零。** 策略不知道自己是否真的持有，实时链路与回测都会对未持仓的股票跑一遍卖出判定（波段策略把整个池当交易域），那些信号不会成交。用「有没有基准」区分：有基准说明此前发过买入信号且尚未卖出平掉，这笔卖出才对应一次真实往返。不加这层过滤，计数会被未持仓的判定凭空虚增，或被打断。

### 接入方式

熔断挂在新拆出的 `BaseStrategy._sync_signal_state()` 上，它由所有路由（基类 `handle_minute_bar` / `handle_tick_bar`、波段重写的 `handle_minute_bar`）在返回前调用，并用它的返回值代替原来的 `matched`。上一轮已有的 `_sync_buy_signal_price` 因此改名（它不再只同步买入信号价）。被否决的买入信号**不能提前 return**：实时链路恒传空持仓，持仓股的卖出判定正是靠「买入不成立 ⇒ 继续走卖出分支」才跑得到的；但落到卖出分支后 `extra` 会被覆盖，所以熔断原因单独留存、在卖出也没信号时还回去，否则引擎日志里只会打出卖出侧的原因。

熔断生效时在日志里记一条 INFO（只在计数**首次**达到阈值那一刻），内容是「连续 N 次亏损卖出 ⇒ 当日不再买入该股」。不在否决处打日志：被否决的信号每分钟都会重现，会刷满整天。

结果：**9 组全部逐笔一致**（`trades` 数组逐字段相等，总收益完全相同）。重构没有改变原有行为。

## 五、空转有没有被压住

| 策略 / 池 | 再入场（关 → 开） | 二次止损占比（关 → 开） |
|---|---|---|
| 波段 / 实际持仓 | 65 → 35 | 42% → 69% |
| 波段 / 自选股 | 92 → 44 | 49% → 66% |
| 波段 / 科技池 | 131 → 65 | 44% → 57% |
| 成交量 / 实际持仓 | 29 → 7 | 93% → 100% |
| 成交量 / 自选股 | 32 → 11 | 81% → 91% |
| 成交量 / 科技池 | 80 → 27 | 80% → 100% |

再入场的**绝对笔数**降了约一半到四分之三，但**二次止损比例反而升高**。这两件事不矛盾：熔断挡掉的是「当天第 3 次以后」的往返，剩下的仍是同一天内较早的往返，它们本来就是这个循环里最容易再被止损的部分。也就是说熔断把循环压小了，没有消除它。

若要真正消除，需要把规则改成「**一天内该股只允许一次往返**」（成交后当天不再买该股），而不是靠计数熔断。这是与本次不同的设计选择，没有在这次实验里测。

## 七、结论

1. **熔断是这轮改动里第一个带来明确正收益的机制。** 九组均值 +10.58pp，波段三组全部转正（-20.74% / -31.88% / -9.23% → +4.23% / +4.00% / +18.66%）。对照上一轮：新止损净效果 -0.14pp，量比 NaN 修复无法从混口径里分离。熔断与前两者的区别在于它直接压缩笔数，而前两者只是改变单笔盈亏的形状。

2. **收益来源仍是「少交易」，不是「交易得更好」。** 波段单笔期望没变，笔数掉到四成；成交量单笔期望变差。这说明被砍掉的那些往返本身不赚钱，熔断的贡献是止损。

3. **风险侧是回撤全面下降**，波段自选股从 33.10% 降到 16.30%。综合本金曲线看，熔断同时改善了收益与回撤，是本次最干净的一组结果。

4. **成交量策略没有被熔断救回来**（+8.32 / -3.21 / +0.78pp）。它的单笔期望本来就比波段差一倍以上（-0.6% ~ -1.2%），而熔断只减少次数、不改善单笔。要提高成交量策略的表现，需要动它的选股与买入条件，不是加过滤器。

5. **卖出侧熔断会挡住硬止损，这是设计选择需要确认。** 当日连续 3 次卖飞后不再卖出，意味着持仓在当天下午遇到急跌时无法离场，要等次日。本次回测里这个副作用没有表现为回撤恶化（回撤反而下降），但区间内没有出现午后单边急跌的样本。建议在实盘或更长的区间上单独验证这一条。

6. **强趋势策略现在也吃到了熔断**，但它仍然没有新止损。两个机制在三个策略上的接入是不对称的，这一点从上一轮起就存在，本次没有改变。
