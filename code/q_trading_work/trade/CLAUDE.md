# CLAUDE.md

执行交易模块.

## Project Overview

在回测或者策略运行时，产生买卖订单，交易模块根据买卖订单发出实际买卖操作
当接收到订单时，向接收者发送推送通知

**交易通知推送**
通过配置文件中的推送链接，支持企业微信的推送, 微信推送等
- 企业微信推送: 通过配置推送链接，按照企业微信消息格式进行推送
- 发送微信消息: 通过itchat给微信好友发送消息

**交易管理**
交易管理用来管理所有交易流程，每个订单由对象OrderDao实现，每个订单需要通过API接口保存到服务器

- 订单包含买入或者卖出，股票，委托数量，交易价格，交易数量，订单状态
- 订单状态包含：委托，成功，失败
- 接收到订单请求后，返回订单对象以及一个订单id
- 订单数据需要通过API保存到服务器
- 实现交易推送
- 维护交易定时器
- 定义异步回调，把订单执行结果通过回调返回给投送者


**交易定时器**
交易管理维护一个定时器，每接收一个订单，就触发定时器进行操作，订单状态初始为委托状态，定时器执行后成功或者失败修改订单状态，并更新服务器

**交易滑点**
交易滑点，在实际买卖时，实际交易价格为委托价格增加几个百分率，比如滑点为0.1,则在买入时增加0.05，和卖出时较少0.05，为了快速成交

**交易手续费**
实际交易都要有手续费，为了体现实际收益，增加手续费，手续费会在买卖时都增加一定比例的成本
