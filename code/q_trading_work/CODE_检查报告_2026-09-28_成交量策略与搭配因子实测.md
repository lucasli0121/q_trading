# 成交量策略与搭配因子实测

日期：2026-09-28
数据来源：服务端 `/api/market/kline/day`（本端 `MarketDataApi`）+ 本地临时脚本离线计算
配套代码：`strategy/volume_expansion_strategy.py`、`cfg/strategy.yaml`、`tests/strategy/test_volume_expansion_strategy.py`

---

## 一、结论摘要

1. **成交量因子自身在该样本内是负向的**。因子定义的买入阈值（`score >= 4`）对应 5 日超额收益 **−1.03%**（n=271，超额胜率 38%），按日截面 Spearman IC **−0.156（t=−3.19）**，前后半段分段同号。也就是说，「放量」在这个区间里更接近情绪高点与派发，而不是趋势起点。
2. **与成交量互补、而不是重复的因子只有「支撑/阻力位」这一族**。`BollSRFactor` 截面 IC **+0.166（t=+3.43）**、`KlineSRFactor` **+0.124（t=+2.74）**，是全部被测因子里仅有的两个正 IC；它们与成交量打分负相关（−0.494 / −0.240），信息独立。趋势/动量类因子与成交量正相关 0.10~0.42，且 IC 全部为负，叠加只会放大同向风险。
3. **策略默认仍按因子原义（`volume_mode = momentum`，放量看多）落地**，搭配因子默认 `boll_sr`。实测方向（缩量看多，`V<=0` 且 `boll >= 0` → 5 日超额 **+1.24%**）通过 `match.volume_mode = reversion` 一行切换。
4. 参数默认值：`partner_min_score = 0.0`（等价于「不在阻力区、未跌破支撑」）。依据是单因子分组：`boll > 0` +0.97%、`boll == 0` +0.02%、`boll <= -5` −0.93%，正档与 0 档都不算差，负档才明显变差。

## 二、数据与口径

### 2.1 样本

| 项 | 值 |
| --- | --- |
| 股票数 | 43 只（2026-09-24 有日K的全部标的） |
| 交易日区间 | 2026-07-01 ~ 2026-09-16 |
| 交易日数 | 56 天 |
| 样本数 | 924 个「窗口 40 根」观测 |
| 每日平均样本 | 16.5 只 |

股票池是怎么来的：先按 `stock_info/list` 分页（每页 100 条）拉取，再与用户股票池合并得到 302 个代码；逐个请求日K后，只有 79 只返回数据，其中 43 只长度 ≥ 47 根（窗口 40 + 持有 5 + 缓冲 2），构成最终样本。服务端日K只保留约 3 个月，这是样本量的硬上限。

### 2.2 计算口径

- **窗口**：40 根日K，与 `StrategyWorkflow.SELECT_KLINE_DAYS` / `BacktestConfig.signal_window` 一致。因子内部周期按各自默认（成交量 20 日、布林带 20、K线SR 10、均线 5 等）。
- **持仓模拟**：t 日收盘产生信号 → **t+1 开盘买入** → 持有 **5 个交易日** → 收盘卖出。收益 = (卖出收盘 − 买入开盘) / 买入开盘。
- **超额收益**：按交易日去均值，`ex = fwd − 当日全样本 fwd 均值`。目的是剔除市场 beta，避免整段行情涨跌淹没因子差异。
- **截面 IC**：每个交易日对全部股票算签名秩相关（Spearman），再对 56 个交易日的 IC 求均值与 t 值（`t = mean / (std / sqrt(天数))`）。
- **胜率**：指**超额收益胜率**，不是绝对收益胜率。
- **成交量打分**：`VolumeExpansionFactor(days=20).score(win)["score"]`，10 分制，`>=6` 为因子定义的 STRONG_BUY、`>=4` 为 BUY。

### 2.3 未扣除的部分

未扣手续费、印花税与滑点。5 日持有窗口在相邻交易日之间**相互重叠**，样本不独立，t 值被系统性高估。这两点在解读倍数差异时要注意，但方向性结论（正/负号）对这种偏差不敏感。

## 四、与成交量的信息冗余度

冗余度用「同一窗口内因子打分与成交量打分的相关系数」衡量。相关系数越高，说明两个因子在讲同一件事。

| 搭配因子 | corr(因子, 成交量) | 是否互补 |
| --- | --- | --- |
| **BollSR 布林带位置** | **−0.494** | 互补（反向） |
| **KlineSR 支撑阻力** | **−0.240** | 互补（反向） |
| MultiROC 多周期涨幅 | +0.105 | 近独立但 IC 近 0 |
| PriceTrend 结构 HH/HL | +0.167 | 重复 |
| RegressionTrend 回归斜率 | +0.215 | 重复 |
| Adx 趋势强度 | +0.246 | 重复 |
| MinCloseDecline 高到低收% | +0.261 | 重复 |
| LowRebound 低点反弹% | +0.304 | 重复 |
| ROC 涨幅% | +0.334 | 重复 |
| CloseRebound 低收反弹% | +0.349 | 重复 |
| Ma 均线排列 | +0.384 | 重复 |
| HighDecline 高点回撤% | +0.414 | 重复 |
| Vwap 均价偏离% | +0.415 | 重复 |
| MultiTrend 趋势复合 | +0.422 | 重复 |

支撑/阻力位因子与成交量**负相关**，这是它唯一值得作为搭配因子的根据。其余因子要么正相关（重复），要么 IC 近 0（无信息）。

### 4.1 与成交量的二维组合

分组口径：`V` 高 = `V >= 4`（271）、`V` 低 = `V < 4`（653）；`BollSR` 低 = `boll <= -5`（246）、`BollSR` 高 = `boll >= 0`（678）。两组各自穷尽全部 924 个样本，因为布林带打分取离散值（实测只出现 `10 / 7.5 / 5 / 0 / -5 / -7.5 / -10`），门槛两侧不存在中间区间。

| 组合 | n | 超额均值 | 超额胜率 |
| --- | --- | --- | --- |
| `V` 高 × `BollSR` 高 | 127 | **−1.609%** | 37.8% |
| `V` 高 × `BollSR` 低 | 144 | −0.527% | 38.2% |
| `V` 低 × `BollSR` 高 | 551 | **+0.785%** | 54.1% |
| `V` 低 × `BollSR` 低 | 102 | **−1.495%** | 38.2% |
| `V` 高 × `KlineSR` 高 | 191 | **−1.660%** | 36.1% |
| `V` 低 × `KlineSR` 高 | 545 | **+0.801%** | 54.3% |

在 `momentum`（放量看多）语义下，`V` 高已经把超额拖到 −1.6%；再叠加 `BollSR` 高，两组都没有改善。而在 `reversion` 语义下，`V` 低 × `BollSR` 高是唯一稳定为正的格子（n=551，+0.785%，胜率 54.1%），`V` 低 × `BollSR` 低则是 −1.495%。这说明搭配因子的作用不是「加一道保险」，而是**决定放量信号该往哪个方向读**。

### 4.2 三维分档矩阵（超额均值）

`boll` 取值只有离散档位，因此中列实际等价于 `boll == 0`（价格在中轨下方但未触及下轨）。

| | `boll <= -5` | `boll == 0` | `boll >= 0` |
| --- | --- | --- | --- |
| `V <= 0` | n=16 **−1.866%** | n=73 +0.435% | n=51 **+1.238%** |
| `0 < V < 4` | n=113 −1.156% | n=280 +0.483% | n=164 **+1.011%** |
| `V >= 4` | n=117 −0.580% | n=101 −1.550% | n=9 **−1.214%** |

两件事同时成立：

1. **同一成交量档位内**，`boll` 越高越好（唯一例外是 `V >= 4` 行的 n=9 格，样本过小）。
2. **同一 boll 档位内**，成交量分越高越差。

`boll >= 0` 这一列里，成交量从低到高的三档分别是 +1.238% / +1.011% / −1.214%，单调下降。`V < 4 且 boll >= 0` 合计 **+1.06%（n=215）**，是该样本里最稳的正超额组合。三列样本量 246 / 454 / 224，与 5.1 节的单因子分组一致。

## 六、局限

1. **样本量**：43 只股票、56 个交易日、单一市场阶段。这是服务端日K只保留约 3 个月导致的硬约束，不是采样选择。
2. **样本重叠**：5 日持有窗口逐日滚动，相邻观测高度重叠，t 值与胜率都被高估。
3. **未计成本**：未扣手续费、印花税、滑点。按单边千分之一估算，5 日持有大约吃掉 0.2%~0.3%，不影响本报告的方向性判断，但会压缩正超额组的绝对水平。
4. **因子版本变动**：`BollSRFactor` 于 2026-09-28 改过档位定义，本报告的 `boll` 分布与分组均基于新定义。
5. **成交量的极端档**：`V > 6` 只有 59 个样本，其 +0.204% 不足以得出「极端放量转正」的结论。

上述方向结论定位为**提示**而非**定论**。策略因此把成交量方向做成参数（`match.volume_mode` / `buy.volume_mode`），默认取因子原义 `momentum`，切换为 `reversion` 只需改一行配置，两种模式共用同一套打分、门槛与卖出逻辑。

## 七、落到代码的对应关系

| 实测结论 | 代码位置 |
| --- | --- |
| 搭配因子族 = 支撑/阻力位 | `PARTNER_FACTORS` 注册表，`boll_sr` / `kline_sr`；默认 `MATCH_PARTNER_FACTOR = "boll_sr"` |
| 门槛 `>= 0` 而非 `> 0` | `MATCH_PARTNER_MIN_SCORE / BUY_PARTNER_MIN_SCORE = 0.0`，判定用 `>=` |
| 搭配因子可选切换 | `match.partner_factor` / `buy.partner_factor`，非法值回退默认 + `logger.warning` |
| 成交量方向可配置 | `MODE_MOMENTUM` / `MODE_REVERSION`，`match.volume_mode` / `buy.volume_mode` |
| 放量看多为默认 | `MATCH_VOLUME_MODE = MODE_MOMENTUM`；`cfg/strategy.yaml` 的 `volume_expansion_strategy.match.volume_mode: momentum` |
| `reversion` 语义 = 放量否决 | `_combine()` 内 `volume_ok = volume_score <= quiet_threshold` |
| 数据不足必须拦在计算之前 | `PARTNER_FACTORS` 的第 3 元「最少K线数函数」（adx = `2 * days`，talib lookback）；`_partner_score` 不足时返回 `None` 而不是 0.0 |

## 八、复现方式

临时脚本 `_study.py`（各因子分组 + IC + 二维组合）与 `_study2.py`（门槛扫描 + 三维矩阵）已随本次工作删除，逻辑如下，可随时重建：

1. 从服务端拉日K：`MarketDataApi` / `/api/market/kline/day`，**必须带起止日期**（不带日期会 500）。只保留长度 ≥ 47 根的标的。
2. 对每个标的按 40 根窗口滚动，取 `VolumeExpansionFactor(days=20)` 与各搭配因子的 `score()`；`VolumeExpansionFactor.score()` 返回 **dict**，取值要用 `["score"]`，其余因子返回 float。
3. 收益：t+1 开盘买、t+5 收盘卖；按交易日去均值得到 `ex`。
4. IC：逐日 Spearman 秩相关，对天数求均值与 t 值。

数据可行性上有一个前提：服务端日K只有约 3 个月，且 `stock_info/list` 每页最多 100 条。要在更长时间窗口上复测，需要先把日K落库或切换到支持更长历史的行情源。
