# CLAUDE.md

策略运行工作流

## Project Overview

策略工作流主要功能：加载策略，管理策略，执行策略，交易订单，记录日志

### 工作流基类

- 工作流基类可以定义线程池供子类继承
- 订阅mqtt消息，获取分钟消息和实时消息推送回调
- 实现分钟级handle_bar()函数，和实时级handle_tick函数
- 子类可以继承handle_bar和handle_tick函数

### 策略工作流

实现交易实例对象

**加载策略**
读取数据库保存的策略，根据数据库保存的策略类名生成策略对象
- 读取数据库已有策略，使用策略管理器加载策略

**管理策略**
根据策略类名加载策略后，采用策略管理器统一管理，可以对策略进行停止，运行，删除等操作

**执行策略**
采用线程池模式执行策略，继承基类的线程池模型
- 继承基类的handle_bar()函数，和实时级handle_tick函数
- 在handle_bar函数中实现策略流程的执行

**交易订单**
根据策略返回的买卖明细产生交易订单
- 订单提交给订单管理，订单管理会通过异步回调订单的交易结果

**记录日志**
- 保存流程日志

## 编码规范

- 所有函数必须有类型注解，代码符合pylance规范
- 所有函数都要求函数注释，文件头，函数头注释
- 函数参数，类成员定义都要求有类型说明
- 字符串一律使用双引号
- tests目录测试符合unittest规范
