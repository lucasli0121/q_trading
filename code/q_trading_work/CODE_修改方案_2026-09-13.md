## 二、workflow 层（加载 / 调用 / 下单 / 盈亏）

### P1-14 信号记录与对外推送发生在所有过滤之前
**修改方案**: 黑名单和股票池在handle_bar中submit之前已经做了过滤，在_save_trade_signal之后再过滤股票池其实没有意义
trade_signal只是买卖信号，系统设计只要是买卖信号都应该通知用户，在途和持仓的判断在创建订单之前，创建订单是由初始资金，持仓最大个数等来判断
signal信号是直接通知给用户，由用户判断是否进行真实交易，系统中的订单，持仓算是模拟交易。
