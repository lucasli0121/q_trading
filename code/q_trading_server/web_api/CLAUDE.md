# web_api Claude.md

## web_api 目录说明

- 通过FastApi实现股票数据的访问接口，同时为接口提供操作说明

### 股票池管理接口

- 股票池是用户定义的可以用来监控的股票池标的，作为用户自定义股票池，用户可以随时添加和删除

**创建股票池**: 根据用户关系创建股票池名称和描述

**删除股票池**: 删除用户指定的股票池
**查询股票池**: 根据用户id查询股票池
**股票池添加股票**: 向股票池添加股票
**从股票池剔除股票**: 从股票池剔除指定的股票
**获取股票池的股票**: 根据根据用户id，股票池名称查询股票池中所有的股票

### 用户管理

- 提供用户注册登录，并实现用户和股票池，策略的关系
**用户注册**: 实现用户注册接口
**用户登录**: 实现用户登录接口

### 策略管理

- 实现用户策略管理
**策略创建**: 创建用户策略
**保存回测结果**: 保存用户回测的结果
**查看回测结果**: 查看用户回测结果
**保存运行记录**: 保存运行策略的记录
**查看运行记录**: 运行策略产生的运行日志，log等

### 因子管理

- 因子是策略使用的选股因子定义，由管理员创建和管理
**因子创建**: 管理员创建因子定义（名称、类路径、类名等）
**删除因子**: 删除指定名称的因子
**因子列表**: 查询所有因子定义
**因子详情**: 按名称或记录 ID 查询单个因子详情

### 行情管理接口

**实时股票查询接口**: 通过SockFetch对象查询实时股票数据，提供json格式
**日K数据查询**: 通过StockFetch对象查询历史K线数据
**分钟K线数据查询**: 查找频率为分钟的行情数据

### 财务数据管理接口

**查询公司基本信息**: 可以查询到公司股本，市盈率，基本资料等
**查询公司的利润**: 可以查询到公司的最近的利润，利润率等
